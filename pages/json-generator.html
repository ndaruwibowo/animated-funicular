Generator JSON dari Struktur Folder

Petunjuk Penggunaan:

  1. Klik tombol Choose Files di bawah ini.
  2. Pilih folder dari perangkat Anda (semua sub-folder akan ikut terbaca).
  3. Tunggu hingga sistem selesai memetakan struktur file ke dalam format JSON.
  4. Klik tombol Download JSON untuk menyimpan hasilnya secara lokal.
